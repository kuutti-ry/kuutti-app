# rewards

The earned, non-transferable reward ledger (TD-15), and the invitations that earn into it (#107, ADR-044): Settings › Invitations makes a code, shares it, withdraws an open one, takes a code from somebody else, and says what invitations earn and what they earned; onboarding offers a code once, after the consents. Other slices import only `index.ts`.

- `Invitations.tsx`: Settings › Invitations, which the settings slice wraps in its page. For a person whose profile has passed the gate's test: what an invitation earns today, Make an invitation, the code just made, shown this once (large, selectable, read a character at a time) with Share the code, which hands the phone's share sheet the invitation's message (`invite.share.message`: free, bank-verified, the website and the code, nothing about the sender; the sheet is injected, as the export's is), until a read that once listed it lists it no more (a friend used it, or it was withdrawn); the open invitations by when they were made, each withdrawn after a dialog; how many counted and what waits to be used. Anybody else reads that invitations open once the profile is complete, and whoever may still type a code finds its field. Nothing names a friend, or says that one used a code and has not finished. Every outcome is said in a live region and, on iOS, aloud.
- `RedeemInvitation.tsx`: a code's field and Use the code, dimmed until what is typed reads as a code the way the API reads it (`normaliseInvitationCode`, `INVITATION_CODE_PATTERN`), so a slip costs none of the day's tries; the refusals in the API's words (`errors.invitation_*`).
- `InvitationStep.tsx`: onboarding's optional step right after the welcome, the field and Skip, then the thanks and Continue. Onboarding (the identity slice) offers it once a walk, while the name is still to come, when `fetchInvitations` says `redeemable`; a read that fails passes it over.
- `useInvitations.ts`: the read when the screen comes to the front and when the app comes back to the foreground, as `useGate` reads the gate. `client.ts`: `GET /invitations`, `POST /invitations`, `DELETE /invitations/{id}`, `POST /invitations/redeem`.
- `words.ts`: `rewardParams`, which picks the sentence for the kinds a reward holds, for the screen and for the home screen's notice that an invitation counted.
