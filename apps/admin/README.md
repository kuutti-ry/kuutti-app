# @kuutti/admin

Vite + React moderation panel, built to static files and served behind CloudFront. Screens so far, each at its own path with a menu by role (#302): the staff sign-in (`src/features/identity`, #49, ADR-006), the photo review queue at `/photos` (`src/features/media`) and the feedback people sent from the app at `/feedback` (`src/features/safety`, #171), a person's page at `/accounts/:id`, reached by an account id from a queue item, a feedback row or the lookup at `/accounts` and never by a search (#306), and for admins the tunables at `/config` (#304, #305), the audit log at `/audit`, fifty rows a page and never all at once (#309), and the staff list at `/staff`, read-only (#310); the front page at `/` says what waits in each queue and for how long, against the response time of `matching_config moderation_response_hours` (#303). The rest arrives with the Admin milestone (#106). Rules: `.claude/rules/admin.md`.
