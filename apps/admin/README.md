# @kuutti/admin

Vite + React moderation panel, built to static files and served behind CloudFront. Screens so far, each at its own path with a menu by role (#302): the staff sign-in (`src/features/identity`, #49, ADR-006), the report queue at `/reports`, the reports waiting the oldest first, those about one person together, with both people's histories, and the decided ones behind a filter; a member of staff never sees a report they are a party to (`src/features/safety`, #311), the photo review queue at `/photos` (`src/features/media`) and the feedback people sent from the app at `/feedback` (`src/features/safety`, #171), a person's page at `/accounts/:id`, reached by an account id from a queue item, a feedback row or the lookup at `/accounts` and never by a search (#306), with the sanctions on it: warn, hide, suspend until a day and for admins ban, each through a confirm dialog, then lifted or looked at again by somebody else (#308), and for admins the tunables at `/config` (#304, #305), the audit log at `/audit`, fifty rows a page and never all at once (#309), and the staff list at `/staff`, read-only (#310); the front page at `/` says what waits in each queue and for how long, against the response time of `matching_config moderation_response_hours` (#303), and how many told Kuutti they found someone, by reason, over the last thirty Finnish days and in all, naming nobody (#83, ADR-040). The rest arrives with the Admin milestone (#106). The look is shadcn/ui's components on Tailwind v4 (`src/components/ui/`, the tokens in `src/tokens.css`), compiled into one static stylesheet for the host's CSP (ADR-050). Rules: `.claude/rules/admin.md`.

Hosted at `https://admin.staging.kuutti.app` (#313, ADR-025): `admin-deploy.yml` builds `main` against the staging API and syncs it to a private bucket behind CloudFront (`infra/modules/admin`), and a pull request's build is `/pr-<n>/` of the same host, also against the staging API, which is why the router takes `BASE_URL` as its basename. Production's `https://admin.kuutti.app` is built the same way from a `v*` tag. Locally, `pnpm dev:admin` (or `pnpm env:up`) serves it at `http://localhost:5173` against the local API.

Tests: Vitest with Testing Library for every screen (`pnpm --filter @kuutti/admin test`), and the flows in a real browser, Playwright in Chromium against the production build under the host's CSP, the mock bank and an API of their own (`pnpm e2e:admin`, `e2e/README.md`, ADR-051).
