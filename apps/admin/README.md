# @kuutti/admin

Vite + React moderation panel, built to static files and served behind CloudFront. Screens so far: the staff sign-in (`src/features/identity`, #49, ADR-006) the photo review queue (`src/features/media`) and the feedback people sent from the app (`src/features/safety`, #171); the rest arrives with the Admin milestone. Rules: `.claude/rules/admin.md`.
