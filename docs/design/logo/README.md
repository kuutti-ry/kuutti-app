# The logo

The seal pup's face, drawn by Gaiane, Kuutti's designer: the thick-stroke version the maintainer gave on 23/10/2026, the one kuutti.app shows. The two files are the masters every logo file in this repository is made from.

- `seal-face-light-2000.jpg`: the outline, ink `#232323` on paper `#FCFCFC`, 2000 px.
- `seal-face-dark-2000.jpg`: the filled face, light on her ink, 2000 px.

`apps/mobile/scripts/logo/icons.mjs` makes the app's icons, its splash images, the favicon and the mark beside the name in the app and the panel from them (`node scripts/logo/icons.mjs` in `apps/mobile`). A vector master would replace both files and change nothing else (#409).
